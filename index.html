DANTES-GNSS : Setup Guide

Physical layout

This system works with three sky-facing antennas in a straight line, each ~0.28m apart, connected to receivers reachable on ports 5001 - 5000 - 5002 (left to right).
The middle receiver (5000) is used as the common RTK base for both baselines.

Step 1. Install RTKLIB

Download RTKLIB from rtkexplorer.com (or the GitHub repo). The system requires RTKNAVI.exe, and STRSVR.exe to communicate with the receivers.

Step 2. Launch STRSVR

open STRSVR and configure:

Setting (0) Input (1) Output
Type TCP Client TCP Server
Server Address 143.117.216.46 5000
Port - - - 6000

Example STRSVR Setup:

As port 5000 can only accept one client connection at a time, run STRSVR first: input = TCP Client to port 5000, output = TCP Server on a new local port (e.g. 6000), then point both RTKNAVI base inputs at that port instead of 5000 directly.

Step 3. Launch two RTKNAVI instances

Each instance computes one baseline. Open RTKNAVI twice and configure:

Setting Instance A Instance B
Rover input (Stream 1) TCP Client → port 5001 TCP Client → port 5002
Base input (Stream 2) TCP Client → port 5000 TCP Client → port 5000
Solution 1 output TCP Server, port 6001 TCP Server, port 6002
Solution format E/N/U-Baseline E/N/U-Baseline
Positioning mode Kinematic Kinematic
Ambiguity resolution Fix and Hold Fix and Hold

The Solution 1 output ports (6001 / 6002) must match the BASELINES list at the top of server.py - change one side or the other if you use different ports.

Step 4. Start the dashboard

Run launch.bat. It sets up the Python virtual environment, installs requirements.txt, and starts server.py, which connects to both RTKNAVI solution ports and opens this dashboard automatically.

Final Results

Once RTKNAVI achieves a fixed solution (Q=1) on both instances, the status badge should read NORMAL and both baseline distances on this dashboard should settle close to 0.28m. A sustained deviation beyond tolerance, especially without a corresponding drop in fix quality, is the signature this system is designed to flag as an ALARM.
